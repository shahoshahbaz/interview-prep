# 🎯 How to Use Cheat Sheets for Interview Prep

> **Battle-tested, interview-oriented workflow that actually works.**

---

## 📋 Phase 0: Before You Start Practicing (One-time Setup)

**Goal:** Create consistent, effective cheat sheets

Each pattern cheat sheet should be **1 page max** and always have these sections **in this exact order**:

1. **Pattern name** → Clear identification
2. **When to recognize it** → Signals & keywords to spot
3. **Core idea** → 1–2 sentences explaining the concept
4. **Template / skeleton code** → Copy-and-adapt structure
5. **Common traps** → Mistakes to avoid
6. **Time & space complexity** → Big-O analysis
7. **1–2 canonical problems** → Real examples

**Key principle:** Consistency matters more than content. Same structure = faster recall.

---

## 🚀 Phase 1: First Attempt (NO Cheat Sheet Allowed)

**Duration:** 10–20 minutes max

**This is non-negotiable.** Your brain must struggle first.

### Steps:

1. ✅ Read the problem carefully
2. ✅ Identify:
   - Input type
   - Expected output
   - Constraints
3. ✅ Try to solve from scratch
4. ✅ Write your solution

### Rules:

- ❌ Do NOT open the cheat sheet
- ❌ Do NOT jump to solution
- ✅ Even a wrong approach is valuable

**👉 Key insight:** If you immediately peek, your brain never learns pattern recognition.

---

## 🔍 Phase 2: Pattern Diagnosis (Cheat Sheet Allowed — But Limited)

**Duration:** 2–3 minutes

**Purpose:** Diagnose what you missed, not copy answers.

### Steps:

1. ✅ Look ONLY at these sections:
   - "When to recognize it"
   - "Core idea"
2. ✅ Ask yourself these questions:
   - Did I identify the right pattern?
   - If not, why? What clue did I miss?
3. ✅ Write 1 line of reflection:
   - _"Missed pattern because I ignored ___"_

### Why this works:

This step builds interview intuition fast by forcing you to understand what signals you missed.

---

## 🛠️ Phase 3: Structure Correction (Template-Only)

**Duration:** 5–7 minutes

**Purpose:** Learn the correct skeleton, not memorize full solutions.

### Steps:

1. ✅ Rewrite your solution using the template skeleton
2. ✅ Fill in ONLY:
   - Variable names
   - Loop conditions
   - Base cases
3. ✅ Adapt values to your problem

### Rule:

- ❌ Do NOT copy full code line-by-line
- ✅ You're training **muscle memory**, not memorization

---

## ⚠️ Phase 4: Trap Check (This is Where Seniors Win)

**Duration:** 2–3 minutes

**Purpose:** Prevent repeat failures.

### Steps:

1. ✅ Read ONLY the "Common traps" section
2. ✅ Ask yourself:
   - Did I hit one of these traps?
   - Why does this trap exist?
   - How do I prevent it next time?

### Example:

```
Trap: "Forgot to shrink window"
Result: Infinite loop
Prevention: Always shrink before checking condition
```

---

## 🧠 Phase 5: Lock It In (Active Recall)

**Duration:** 2 minutes

**Purpose:** Prove you own the pattern.

### Steps:

1. ✅ Close all materials
2. ✅ Answer out loud or write on paper:
   - What pattern was this?
   - What was the key insight?
   - What mistake would I make next time?

### Rule:

- If you can't explain it simply → **you don't own it yet**
- Go back to Phase 2-3 and retry

---

## 💪 Phase 6: Pattern Stress Test (Critical)

**Duration:** 20–30 minutes

**Purpose:** Prove you can apply it independently.

### Steps:

1. ✅ Find 1 more problem of the same pattern
2. ✅ Solve it with these rules:
   - ❌ No cheat sheet
   - ✅ Faster than last time
   - ✅ Cleaner code

### Success Criteria:

- If you solve it smoothly → Pattern partially mastered
- If you struggle again → **Pattern not mastered yet**, return to Phase 2

---

## ✏️ Phase 7: Cheat Sheet Update (Most People Skip This)

**Duration:** 2–3 minutes

**Purpose:** Make the cheat sheet YOURS.

Your cheat sheet is a **living document**, not static reference.

### After solving, add:

- ✅ Your mistake (and why it happened)
- ✅ Your phrasing (words that click for you)
- ✅ Your mental shortcut (personal trigger)

### Example:

```
Original: "Think about window size"
Your version: "If array + max/min + subarray → sliding window FIRST"

Original: "Track boundaries"
Your version: "Always save next before reversing pointer"
```

**Result:** The sheet becomes personalized and infinitely more useful.

## 🎓 How This Looks in Real Interview Prep

### Before (Without This Workflow):

❌ You spend hours reading cheat sheets  
❌ You solve problems  
❌ You forget patterns 1 week later  
❌ You repeat same mistakes  

### After (With This Workflow):

✅ You solve a problem from scratch  
✅ You diagnose what pattern you missed  
✅ You understand the template structure  
✅ You identify common traps  
✅ You explain it in your own words  
✅ You stress test with another problem  
✅ You update your cheat sheet  

### The Result:

Your brain will **auto-trigger**:

- 🧠 "Ah… this smells like **sliding window**"
- 🧠 "This is classic **0/1 knapsack**"
- 🧠 "I need **fast & slow pointers** here"

**That's the goal.** Pattern recognition becomes automatic.

## 🎯 Quick Workflow Summary

| Phase | Name | Duration | What to Do | What NOT to Do |
|-------|------|----------|-----------|----------------|
| **1** | First Attempt | 10-20 min | Solve from scratch | Don't peek at cheat sheet |
| **2** | Pattern Diagnosis | 2-3 min | Check "When to recognize" | Don't copy code |
| **3** | Structure Correction | 5-7 min | Fill in template | Don't memorize line-by-line |
| **4** | Trap Check | 2-3 min | Read "Common traps" | Don't ignore mistakes |
| **5** | Active Recall | 2 min | Explain out loud | Don't skip this |
| **6** | Stress Test | 20-30 min | Solve similar problem | Don't use cheat sheet |
| **7** | Update Sheet | 2-3 min | Add your insights | Don't leave it generic |

## 💡 The Hard Truth (No Sugar-coating)

### ❌ What Doesn't Work:

- Reading cheat sheets ≠ Learning
- Solving once ≠ Mastering
- Copying code ≠ Understanding

### ✅ What Actually Works:

**Pattern recognition is trained through mistake analysis.**

### Use Cheat Sheets As:

- 🪞 **Mirror** → Reflect on what you missed
- 🔧 **Corrector** → Fix your approach
- 💪 **Reinforcer** → Strengthen weak areas

### Do NOT Use As:

- ❌ Answer bank
- ❌ Copy-paste source
- ❌ Shortcut to understanding

```
Phase 1: First Attempt         10-15 min  (NO cheat sheet)
Phase 2: Pattern Diagnosis      2-3 min   (Recognize pattern)
Phase 3: Structure Correction   5-7 min   (Use template)
Phase 4: Trap Check             2-3 min   (Avoid mistakes)
Phase 5: Active Recall          2 min     (Explain it)
Phase 6: Stress Test           20-30 min  (Apply again)
Phase 7: Update Sheet           2-3 min   (Personalize)
────────────────────────────────────────
TOTAL                         ~45 min
```

---

## 🚨 Red Flags (You're Doing It Wrong)

- 🚩 You're on Phase 3 before 10 minutes → Too fast, you haven't struggled
- 🚩 You're copying code word-for-word → Not building muscle memory
- 🚩 You can't explain the pattern in Phase 5 → Go back to Phase 2
- 🚩 You skip Phase 7 → Cheat sheet stays generic
- 🚩 You solve once and move on → Pattern not mastered

---

## ✅ Green Flags (You're Doing It Right)

- ✅ You spend 10-20 min on first attempt alone
- ✅ You can identify the pattern in Phase 2
- ✅ You understand the template structure
- ✅ You caught yourself hitting a trap
- ✅ You can explain the solution in your own words
- ✅ You solve the stress test problem faster and cleaner
- ✅ Your cheat sheet grows with your personal insights
