# Summary of Common Methods

## ArrayList Methods:
- `add(E e)`: Adds an element to the end.
- `get(int index)`: Retrieves an element at the specified index.
- `set(int index, E element)`: Modifies an element at the specified index.
- `remove(Object o)`: Removes the specified element.
- `size()`: Returns the number of elements.
- `contains(Object o)`: Checks if the list contains the specified element.
- `clear()`: Removes all elements.

## LinkedList Methods:
- `add(E e)`: Adds an element to the end.
- `addFirst(E e)`: Adds an element to the beginning.
- `addLast(E e)`: Adds an element to the end.
- `get(int index)`: Retrieves an element at the specified index.
- `set(int index, E element)`: Modifies an element at the specified index.
- `remove(Object o)`: Removes the specified element.
- `size()`: Returns the number of elements.
- `contains(Object o)`: Checks if the list contains the specified element.
- `clear()`: Removes all elements.
