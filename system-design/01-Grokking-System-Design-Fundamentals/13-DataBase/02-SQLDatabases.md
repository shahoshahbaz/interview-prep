# SQL Databases

SQL (Structured Query Language) databases, also known as relational databases, are widely used in software applications. They store data in tables with rows and columns, and relationships between tables are established using primary and foreign keys. SQL databases adhere to ACID properties (Atomicity, Consistency, Isolation, Durability) to ensure reliable data transactions.

## Key Concepts
- **Tables**: Structure data into rows (records) and columns (fields).
- **Primary Key**: Unique identifier for each row in a table.
- **Foreign Key**: Establishes relationships between tables by referencing primary keys.
- **Indexes**: Speed up data retrieval operations.
- **Normalization**: Organizes data to reduce redundancy and improve integrity.

## SQL Language Components
- **Data Definition Language (DDL)**: Create, modify, and delete database structures.
- **Data Manipulation Language (DML)**: Insert, update, delete, and retrieve data.
- **Data Control Language (DCL)**: Manage user permissions and access control.
- **Transaction Control Language (TCL)**: Ensure ACID compliance in transactions.

## Popular SQL Databases
- **MySQL**: Open-source, widely used for web applications.
- **PostgreSQL**: Open-source, known for extensibility and advanced features.
- **Microsoft SQL Server**: Commercial, enterprise-level RDBMS with strong Microsoft integration.
- **Oracle Database**: Commercial, robust, and scalable for mission-critical applications.

## Pros and Cons of SQL Databases
- **Pros**: Adherence to ACID properties ensures data consistency and reliability.
- **Cons**: May not be as flexible or scalable as some NoSQL alternatives for certain use cases.
